A comprehensive collection of 11 professional Gutenberg blocks for WordPress, including advanced heading, buttons, sliders, testimonials, and more.

== Description ==

Professional Blocks Suite is a powerful WordPress plugin that provides 11 essential Gutenberg blocks designed for professional websites. Each block is crafted with attention to detail, offering extensive customization options while maintaining excellent performance and accessibility standards.

= Included Blocks =

1. **Advanced Heading** - Customizable headings with advanced typography controls
2. **Professional Button** - Multiple button styles with hover effects and icons
3. **Feature Box** - Highlight features with icons and descriptions
4. **Testimonial** - Display customer testimonials with ratings
5. **Team Member** - Showcase team members with social links
6. **Content Slider** - Create engaging content sliders with navigation (Main Feature)
7. **Call to Action** - Create compelling call-to-action sections
8. **Icon List** - Create lists with custom icons
9. **Progress Bar** - Display progress with animated bars
10. **Pricing Table** - Create attractive pricing tables
11. **Alert Notification** - Display important alerts and notifications

= Key Features =

* **Native Gutenberg Integration** - Built using only native WordPress components
* **Responsive Design** - All blocks are mobile-friendly and responsive
* **Accessibility Compliant** - ARIA labels and keyboard navigation support
* **Performance Optimized** - Lightweight and fast-loading
* **Customizable** - Extensive styling and layout options
* **Translation Ready** - Full internationalization support
* **Professional Quality** - Enterprise-level code standards

= Content Slider Features =

The Content Slider block is the flagship feature of this plugin, offering:

* Multiple slide support with easy add/remove functionality
* Navigation controls (arrows and dots)
* Auto-play with customizable delay
* Transition effects (slide and fade)
* Pause on hover functionality
* Infinite loop option
* Responsive behavior controls
* Full customization of arrows and dots
* Background images and colors for slides
* Content alignment options

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/professional-blocks-suite` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. The blocks will be available in the Gutenberg editor under the "Professional Blocks Suite" category.

== Frequently Asked Questions ==

= Are these blocks compatible with my theme? =

Yes, Professional Blocks Suite is designed to work with any properly coded WordPress theme that supports Gutenberg blocks.

= Do I need any other plugins? =

No, Professional Blocks Suite is completely self-contained and doesn't require any additional plugins.

= Can I customize the block styles? =

Yes, each block comes with extensive customization options including colors, typography, spacing, and layout controls.

= Is the plugin translation ready? =

Yes, the plugin is fully internationalized and ready for translation into any language.

= Does it work with WordPress multisite? =

Yes, the plugin is compatible with WordPress multisite installations.
